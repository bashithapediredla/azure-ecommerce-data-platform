\# E-Commerce Data Engineering Platform



\## Overview



An end-to-end e-commerce data engineering platform built using

Microsoft Azure, Apache PySpark, Databricks, ADLS Gen2,

Azure Data Factory, Synapse Analytics and Power BI.



The project demonstrates a complete data engineering workflow

from multi-source data ingestion to business analytics.



\## Architecture



Data Sources

→ Azure Data Factory

→ ADLS Gen2

→ Bronze Layer

→ Databricks / PySpark

→ Silver Layer

→ PySpark

→ Gold Layer

→ Synapse SQL

→ Power BI
